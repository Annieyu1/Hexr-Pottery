完成标准:真机抓球有压力;编辑器模拟器能抓球;文档同步。

### M1 训练核心(最小闭环)
全部由我写,你只需要在编辑器里点运行验证。

| 模块 | 内容 |
|---|---|
| `IHapticDevice` + `SimulatedGlove` | 没有手套也能跑流程,每指输出可视化 + 日志 |
| `Stimulus` / `StimulusSet` | 刺激数据结构,2AFC 的标准/比较刺激、目标位置随机 |
| `StaircaseProcedure` | 1 上 2 下(规则待定 Q2),带单元测试 |
| `TrialRunner` | 状态机:呈现 → 探索 → 作答 → 判定 → 反馈 → 记录 |
| `DataLogger` | 逐试次 CSV + 会话 JSON,逐行 flush |
| `SessionManager` | 受试者 ID、手别、配置、跨场景持久 |

完成标准:用空场景和键盘模拟,跑完 40 个试次,生成正确的 CSV,阶梯法收敛合理(单元测试验证)。

**依赖**:Q2(阶梯法规则、阈值定位)——可先做可配置,不阻塞。

### M2 游戏 1:压力 2AFC
| 任务 | 谁 |
|---|---|
| `PressureObject`(取代 `ForceBall`):设置 `strength`,上报抓取/松开/次数/时长 | 我 |
| 游戏 1 场景:两个**外观完全一致**的物体,只有左右位置不同;固定问"哪个更强" | 你搭场景,我写脚本 |
| 选择方式:放入"更强"区域 / 指向 / 按按钮——**待定** | 一起定 |
| 学习阶段 UI:力度进度条;正式阶段无 | 你做 UI,我写数据绑定 |
| 反馈:文字、特效、音效,中性语言(见 04) | 我写 `FeedbackDirector`,你放资源 |
| **健康人预试**:找出有效 `strength` 范围、基准值和初始 ΔI | 你做,我设计记录表 |

完成标准:一个 10 分钟的完整游戏 1,数据完整;健康人能完成并看到明显学习曲线。

**依赖**:H2(压力标定);Q15 世界观不阻塞(先用灰盒)。

### M3 会话流程与治疗师界面一期
| 任务 | 说明 |
|---|---|
| Boot / Hub | 选择受试者、手别、游戏、难度 |
| 30 分钟会话模式 | 3 × 10 分钟自动串联(时长待治疗师确认,做成可配置) |
| 治疗师面板(头显内,带 PIN) | 配置、查看本次汇总、导出 |
| 数据导出 | USB/adb 取文件;格式见 05 |
| 校准向导 | 压力/频率 |

完成标准:从开机到导出数据,不用 Unity 编辑器就能完整跑一次会话。

### M4 游戏 2、3

世界观定稿、资产统一风格、特效与音效、字体与多语言、性能优化(Quest 3 目标 72/90 Hz)、无障碍检查。

## 6. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| FlexR API 拿不到 | 游戏 3 与运动数据受限 | 尽早问公司(第 2 节 #5);游戏 3 先不依赖 FlexR |
