# 01 项目概览与已确定决策

版本:v0.1 草案 · 2026-10-08

## 1. 项目目标

为**轻中度中风后患者**开发基于触觉的**手部感知辨别(sensory discrimination)康复训练**游戏,供治疗师在临床中使用,同时采集可用于科研的数据。

- **科研与转化并行**:先开发**科研版**(参数完整、数据完整),之后再裁剪出转化版(预设方案)。
- **首个落地场景**:新加坡 pilot study 的患者数据采集。暂不联网。
- **最终目标**:训练最终**只靠触觉**判断(不依赖视觉),但学习初期可使用视觉辅助。

## 2. 硬件与平台

| 项 | 内容 |
|---|---|
| 头显 | Meta Quest 3 |
| 手套 | Microtube HexR:每指独立气压 + 振动;配合 FlexR 采集手指运动 |
| 引擎 | Unity 6000.6,Meta XR SDK 205(OVR 路线) |
| HexR 包 | `com.microtube.hexr` v0.9.3 |
| 可用触觉维度 | 气压强度 0.1–1.0;振动频率 0.1–40 Hz、强度 0.1–1.0、峰值比 0.2–0.8;每指气压读数 0–5 |
| 测试 | Meta XR Simulator(无法模拟手套,需自建模拟手套,见 02) |

## 3. 目标患者

- 患侧手可佩戴手套,有轻微抓握、伸指能力,但未完全恢复。
- 参考临床范围:Brunnstrom 4–6 期,FMA-UE 26–66 `[具体入排标准待治疗师/研究方案确认]`。
- 单手(患侧)或双手佩戴:**是否双手有助于康复尚不清楚**,框架须同时支持(见 OPEN_QUESTIONS)。

## 4. 三个小游戏(各为独立场景)

| # | 感知维度 | 说明 |
|---|---|---|
| 1 | 压力力度分辨 | 辨别气压强度差异。已有原型:`Assets/Stage3`(弱/中/强分拣) |
| 2 | 振动频率 / pattern 分辨 | 辨别频率,或振动节律(pattern),二者是否都做 `[待确认]` |
| 3 | 手指定位分辨 | 辨别触觉刺激落在哪根手指 |

> 感知维度仍需与治疗师确认,以上三项是目前已确定的。

## 5. 训练时长

- 暂定单次 **30 分钟** = 3 个任务 × 各 10 分钟。
- **不设置强制休息机制**。
- 以上时长为暂定值,须与治疗师商议(已记入 OPEN_QUESTIONS / FUTURE_WORK)。
