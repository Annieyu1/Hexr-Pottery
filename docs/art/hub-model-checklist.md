# 交付清单：Hub 菜单立体书模型

版本：v0.1 · 2026-10-21 · 配套：设计细节见 `hub-book-brief.md`，代码见 `docs/14-hub-menu-book.md`。

你按这张表做模型，每做完一个 FBX 告诉我，我就把灰盒里对应的部件换掉（组件、动画都保留）。打勾表示已交付并替换。

## 0. 通用规则（每个文件都一样）

- **放哪里**：`Assets/Art/Props/Hub/`，文件名照下表。
- **单位 / 朝向**：1 单位 = 1 米，应用缩放和旋转。Blender 里患者在 **−Y** 一侧，+X 是右手边，+Z 向上。
- **导出**（和 T2 一样）：FBX，Apply Scalings = FBX All，Forward = −Z，Up = Y，勾 Apply Transform；只导出网格 + 空物体；平滑 = Face。
- **物体名必须和表里一模一样**（Unity 按名字找）。表里的"原点"就是这个物体的原点位置。
- **立体件按立起来的样子建**，原点放在折线上，底边贴纸面（z = 0），倒下那一侧不能有东西低于纸面。
- 每个 FBX 尽量 1–2 个材质（调色板贴图）；面数见每行。
- 字（Begin、书签名、标题）**不要建模**，Unity 用文字。

### 2.1 书本身怎么建（Blender 步骤）

单位：米。Z 是高度（离桌面），所有高度都从桌面 z = 0 算起。

| 物体 | X 范围 | Z 范围 | 备注 |
|---|---|---|---|
| `BackCover` | 0 → 0.258 | 0 → 0.004 | Y 方向 −0.173 → +0.173（前后各多出 8 mm），书脊那条边（x = 0）不留包边 |
| `PageBlock_R` | 0.0005 → 0.2495 | 0.004 → 0.026 | Y −0.165 → +0.165 |
| `Page_R` | 0 → 0.25 | 平面，z = 0.027 | 比页块顶面高 1 mm，防止闪烁；法线朝上 |
| `FrontHalf`（空物体） | 原点 x = 0 | 原点 z = 0.026 | Y = 0，旋转全为 0 |
| `PageBlock_L`（`FrontHalf` 的子物体） | 0.0005 → 0.2495 | 0.026 → 0.048 | 和右页块一样大，叠在它上面 |
| `FrontCover`（子物体） | 0 → 0.258 | 0.048 → 0.052 | 和封底一样大，在最上面 |
| `Page_L`（子物体） | 0 → 0.25 | 平面，z = 0.025 | **法线朝下**（贴着右页、藏在页块里），UV 铺满 |

1. 建好右半边三个物体。
2. 建一个空物体 `FrontHalf`，放在 (0, 0, 0.026)；把左半边三个物体建好后设为它的子物体（保持变换）。
3. 检查：把 `FrontHalf` 绕 **Y 轴** 转 180°，左半边应该正好镜像落到 x < 0：封面贴桌面、页块在中间、`Page_L` 法线朝上和 `Page_R` 一样高。检查完**转回 0** 再导出。
4. 不要把左右两半合成一个网格；不要应用 `FrontHalf` 的旋转。

细节：页块侧面（前、后、外侧三面）做一层层书页（凹线或贴图）；靠书缝那一面看不到，可以不做。封面四角圆角、边缘 1 mm 倒角。右页块外侧会伸出书签，书签藏进去的 1 cm 在页块里面，正常。
