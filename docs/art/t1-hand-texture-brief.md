# 贴图说明:T1 模型手(OpenXRRightHand)

版本:v0.2 · 2026-10-19 · 状态:**已完成并接入 Unity**:底色、红晕、褶皱是脚本生成的,指甲是手绘的,法线贴图从指甲和褶皱烘焙而来。下面的步骤留作以后重画或改色时参考。
用途:T1 牵手里患者握住的那只"模型手"。任务逻辑见 `docs/11-learning-t1-t2.md` 的 T1 一节。

## 1. 目标一句话
把 Meta SDK 的 `OpenXRRightHand` 画成**和书房同风格的手**:哑光、柔和、日式动画感,有清楚的指甲和指节,但**不画毛孔、血管、汗毛**。远看是一只温暖的人手,近看是干净的手绘风格。

## 2. 先知道的几件事
| 项 | 情况 |
|---|---|
| 网格 | 约 2300 三角面、1360 顶点,26 根骨骼(OpenXR 骨架,和手部追踪同一套) |
| UV | 有一套 UV(0–1 范围),但原本只用于纯色材质,**可能不适合画画**,先检查(第 4 步) |
| 患者主要看到哪面 | 握手时模型手的**手背、拇指、食指侧面**朝向患者;手掌贴着患者手掌,几乎看不到。**手背和拇指最用心画,手掌简单画** |
| 贴图 | 颜色贴图必做;法线贴图可选(第 7 步),先做颜色贴图,在头显里看过再决定 |
| 不要动的东西 | 骨骼、蒙皮权重、顶点数量、物体名字。只改 UV 和材质 |

## 3. 拿到模型
1. 文件在:`Library/PackageCache/com.meta.xr.sdk.core@<一串哈希>/Meshes/HandTracking/OpenXRRightHand.fbx`(现在的哈希是 `c0efcbf2ba70`,SDK 升级后会变)。
2. **复制一份**到 `art/blender/hand/`(别直接改 PackageCache 里的文件,会被 Unity 覆盖)。
3. Blender:**File > Import > FBX**,默认设置。导入后在 N 面板看尺寸,手长应该约 **0.18–0.20 m**;如果是 18–20 m 或 1.8 m,只记下来,**不要 Apply Scale**(会破坏蒙皮),导出时处理。
4. 存成 `art/blender/hand/T1_PartnerHand.blend`。

## 4. 检查 / 重展 UV
1. 切到 **UV Editing** 工作区,选中手的网格,Tab 进编辑模式,全选。
2. 看 UV:
   - **岛清楚、不重叠、手指没被压成细线** → 直接用,跳到第 5 步。
   - **重叠、乱、拉伸严重** → 重展:**UV > Smart UV Project**,Angle Limit 66°,Island Margin **0.02**。
3. 更好但更费时的做法(可选):手背和手掌沿手侧边切一刀缝(选边 → **Mark Seam**),每根手指沿侧面也切一条,再 **UV > Unwrap**。这样手背是一整块,画起来最顺。
4. 只保留**一套** UV(名字 `UVMap`)。重展 UV 不影响骨骼和动画。

## 5. 建贴图和材质(Blender 4.5 LTS)

### 5.1 选对物体
1. 在 **Layout** 工作区、**Object Mode** 下,在 Outliner(右上)里点**手的网格**(三角形图标,通常叫 `RightHand` 之类),**不是骨架**(小人图标)。
2. 选中后网格是橙色描边。选错成骨架的话,后面进不了 Texture Paint。

### 5.2 整理材质
1. 右边 Properties 面板 → **Material 标签**(红色球图标)。导入的 FBX 一般已经带一个材质(可能叫 `Lit`)。
2. 双击材质名改成 **`T1PartnerHand`**。如果材质名旁边有数字(表示被多个物体共用),点那个数字让它变成单独的一份。
3. 切到 **Shading** 工作区,下方节点编辑器里应该有 **Principled BSDF → Material Output**。没有的话 Shift+A → Shader → Principled BSDF,把 BSDF 输出连到 Material Output 的 Surface。
4. 在 Principled BSDF 上设置:
   - **Roughness = 0.7**(哑光,和书房风格一致)
   - **Metallic = 0**
   - **Specular 区块里的 IOR Level** 保持默认 0.5
   - Base Color 上如果已经连了别的节点,先选中那个节点按 X 删掉。

### 5.3 新建颜色贴图(最省事的做法:让 Texture Paint 自动建)
1. 顶部工作区标签切到 **Texture Paint**。左边是图像编辑器,右边是 3D 视图,已经在 Texture Paint 模式。手如果显示成**紫粉色**,说明还没有贴图,这是正常的。
2. 右边 Properties 面板 → **Tool 标签**(螺丝刀加扳手图标)→ 展开 **Texture Slots** 面板:
   - Mode:**Material**
   - 点右边的 **+** → 选 **Base Color**
3. 弹出的对话框里填:
   - Name:`T1PartnerHand_BaseColor`
   - Width / Height:**1024 / 1024**
   - Color:点色块 → 切到 **Hex** → 输入 `E6B394` → 回车
   - **Alpha:取消勾选**
   - Generated Type:Blank
   - 32-bit Float:不勾
   - 点 **OK**
4. Blender 会自动在材质里建一个 Image Texture 节点,并连到 Principled BSDF 的 Base Color。去 Shading 工作区确认一下:Image Texture 节点的 **Color 输出 → Base Color**,节点上的 Color Space 是 **sRGB**。
5. 回到 Texture Paint 工作区,左边图像编辑器顶部的下拉菜单里选 `T1PartnerHand_BaseColor`。现在手应该是均匀的暖肤色,左边能看到 UV 和贴图。

### 5.4 画笔设置
1. **选笔**:3D 视图左边工具栏选 **Draw**(画笔图标)。笔刷在视图下方的笔刷库(Asset Shelf)里选:
   - 铺大面、画红晕用 **Paint Soft**
   - 画指甲、线条用 **Paint Hard**
2. **大小和强度**:在视图顶部的工具栏里调 Radius(快捷键 **F**,拖动鼠标)、Strength(快捷键 **Shift+F**)。颜色在同一栏的色块里改,一样可以输 Hex。
3. **Bleed(防止接缝露底色)**:Properties → Tool 标签 → **Options** 面板 → **Bleed = 8 px**。它会把颜色往 UV 岛外多延伸 8 像素,贴图缩小或压缩后,接缝也不会露出底色。
4. **关掉镜像**:3D 视图右上角有一个蝴蝶形图标,旁边是 **X Y Z** 三个按钮,确认 **X 没有高亮(不是蓝色)**。手不是左右对称的,开着镜像,画一根手指会同时画到另一边。
5. **只看画的效果**:3D 视图右上角的着色方式选 **Solid**,再点它旁边的小下拉箭头 → Color 选 **Texture**。这样看到的是贴图本身,不受灯光影响。偶尔切到 **Material Preview**(第三个球)看一下带光照的效果。
6. 在 3D 视图里直接画就行,不用在左边的 2D 图上画。2D 图主要用来看 UV 和检查接缝。

### 5.5 保存贴图(很重要)
Blender 保存 `.blend` 文件时**不会**一起保存新建的贴图。贴图名后面有 **\*** 就说明还没存,关掉软件就会丢失。
1. **第一次**:左边图像编辑器 → **Image > Save As**(Shift+Alt+S):
   - File Format:**PNG**,Color:**RGB**,Color Depth:**8**
   - 路径:Unity 工程的 `Assets/Learning/Art/Hand/T1PartnerHand_BaseColor.png`(在文件浏览器里新建 `Art/Hand` 文件夹)
2. **之后**:每画十几分钟按一次 **Image > Save**(Alt+S),或者用 **Image > Save All Images**。
3. 再按 Ctrl+S 保存 `.blend`。`.blend` 记的是贴图的路径,下次打开会自动读回 PNG。
4. 保险做法(可选):**File > External Data > Pack Resources** 会把贴图打包进 `.blend`。但打包后还是要单独 Save As 一份 PNG 给 Unity。

## 6. 画什么(按顺序,一层一层来)

### 6.1 色板
从书房色板(`art-brief.md` §4)推出来的暖色肤色,饱和度低,和蜂蜜木色、奶油墙放在一起不突兀:

| 用途 | 色 | 色号 | 画法 |
|---|---|---|---|
| 底色(手背) | 暖肤色 | `#E6B394` | 整张填满 |
| 手掌、指腹 | 浅粉肤色 | `#F0C6AB` | 大号软笔,强度 0.5 |
| 红晕(指节、指尖、掌根) | 柔珊瑚 | `#D9907A` | 软笔,强度 0.2–0.3,一层层叠 |
| 指缝、手指根部的阴影 | 暖棕 | `#C48669` | 软笔,强度 0.2 |
| 指甲 | 浅粉米色 | `#F1D2C3` | 硬笔 |
| 指甲尖(白边) | 奶油白 | `#F8E9DE` | 硬笔,细 |
| 指甲根部线、褶皱线 | 深珊瑚棕 | `#B97A66` | 细硬笔,强度 0.4–0.6 |

规则:**不要用纯白、纯黑、高饱和红**;最亮和最暗之间不要拉太开(哑光风格的关键)。**不要用接近 `#FFC46B` 的黄**:这个黄色留给反馈提示用。(模型手原来的黄色闪烁已经在 2026-10-19 改成招手动作。)

### 6.2 第 1 层:大块明暗
- 手掌和指腹铺 `#F0C6AB`,和手背的边界用软笔过渡,沿着手侧边。
- 手指根部、指缝里、拇指和食指之间的虎口:薄薄一层 `#C48669` 阴影。

### 6.3 第 2 层:红晕
- **手背的大指节**(指根那一排凸起,MCP 关节):每个画一个小椭圆红晕。
- **每根手指中间那节的背面**(PIP 关节):更小的红晕。
- **指尖**:手心那一侧和指甲周围略红。
- **掌根**(手腕那边的手掌鼓起部分):淡淡一片。
- 强度要低,叠 2–3 次比一次画重好。

### 6.4 第 3 层:指甲(最重要,患者看得最清楚)
- 位置:每根手指**最后一节的背面**,长度约占这一节的 **55–60%**,宽度约占手指宽度的 **70%**。拇指指甲最大、最宽。
- 形状:**圆角长方形**,根部(靠指根)是柔和的弧线,两侧直,前端平。
- 画法:
  1. `#F1D2C3` 硬笔画出指甲形状;
  2. 前端 1/6 画 `#F8E9DE` 白边;
  3. 根部弧线用 `#B97A66` 细线描一下(甲根皮);
  4. 两侧可以不描边,让它自然融进皮肤(更柔和)。
- 五个指甲大小、比例要统一,比单个画得精细更重要。

### 6.5 第 4 层:褶皱线(少就是多)
- **手指背面,中间那节关节上**:2–3 条短弧线,弧口朝指尖,长度约手指宽度的一半。
- **手背大指节上**:1–2 条很淡的短线(可以不画)。
- **手指的手心一侧,每个关节**:1 条横线。
- **手掌**:只画 3 条主掌纹(感情线、智慧线、生命线),很淡,强度 0.3。
- 线全用 `#B97A66`,**细、淡、不闭合**。日式动画风格里,褶皱线是"暗示",不是"描边"。

### 6.6 收尾
- 在 3D 视图里转一圈,检查接缝处有没有底色露出、指甲有没有被 UV 接缝切断。
- 在 Material Preview 里用暖色 HDRI 看一下;再把手放到书房场景的灯光下看一下。
- **Image > Save As** → `T1PartnerHand_BaseColor.png`。

## 7. 法线贴图(可选:指甲立体感和褶皱凹陷)
不用雕刻,画一张灰度高度图,再让 Blender 转成法线贴图:
1. 新建图像 `T1PartnerHand_Height`,1024 × 1024,填 **50% 灰 `#808080`**,色彩空间 **Non-Color**。
2. 在这张图上画(在图像编辑器里把这张设为当前绘制图像):
   - **指甲**:整片稍亮(`#9A9A9A`);**甲根那条线**画暗(`#5A5A5A`),做出"嵌进皮肤"的感觉;
   - **褶皱线**:在颜色贴图褶皱线的同样位置画暗线(`#606060`);
   - 其他地方保持 50% 灰。
   - 小技巧:把颜色贴图临时设成半透明叠在下面,方便对齐;或者直接在 3D 视图里对着颜色贴图画。
3. 转法线:
   1. 材质里加 Image Texture(高度图)→ **Bump** 节点(Strength **0.4**,Distance 0.002)→ 接 Principled 的 Normal;
   2. 再新建一张空图像 `T1PartnerHand_Normal`(1024,Non-Color),在材质里加一个 Image Texture 节点指向它,**选中这个节点**(烘焙会写进被选中的节点);
   3. 渲染器切 **Cycles** → Bake → Bake Type **Normal**,Space **Tangent** → **Bake**;
   4. 保存 `T1PartnerHand_Normal.png`。
4. 检查:法线贴图应该是浅紫蓝色,指甲边和褶皱线处有细细的颜色变化。如果凹凸方向反了(看起来凸起而不是凹下),把 Bump 节点的 **Invert** 勾上重新烘一次。

## 8. 导出
**贴图**:都放到 Unity 工程的 `Assets/Learning/Art/Hand/`(文件夹不存在就新建):
- `T1PartnerHand_BaseColor.png`
- `T1PartnerHand_Normal.png`(如果做了)

**模型**:
- **UV 没改** → 不用导出模型,我直接用 SDK 里的原文件,只换贴图。
- **UV 改过** → 必须导出,否则贴图对不上:
  1. 同时选中手的**网格和骨架**;
  2. **File > Export > FBX**,勾 **Limit to: Selected Objects**;
  3. Object Types:Armature + Mesh;
  4. Transform:**Apply Scalings = FBX All**,Forward **-Z**,Up **Y**;
  5. Armature:**取消 Add Leaf Bones**;
  6. **取消 Bake Animation**;
  7. 存为 `Assets/Learning/Art/Hand/T1PartnerHand_R.fbx`。
