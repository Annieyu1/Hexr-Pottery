# 美术需求文档:书房场景

版本:v0.1 草案 · 2026-10-11 · 状态:**待你确认**(带 `[待确认]` 的是我的提议)

## 1. 一句话
一间小巧精致的日式动画氛围书房:低多边形、哑光、暖色阳光、柔和 AO 阴影、色彩柔和但有层次。患者**坐在椅子上面对书桌**,桌面中间留一块干净的操作区,桌上有两个抓取用的软布球。

## 2. 已定决定(2026-10-11)
| 项 | 决定 |
|---|---|
| 画风 | 低多边形(lowpoly),哑光质感,轮廓明确,材质干净 |
| 光与色 | 温馨温暖、柔和;暖色阳光;烘焙 AO 软阴影 |
| 氛围 | 日式动画(小巧、精致、有生活感) |
| 视角 | 第一人称,患者**坐姿**,面对书桌 |
| 房间 | 小房间,立方体,只做内部 |
| 家具 | 书柜、桌子、桌上台灯(先完成大场景建模) |
| 窗户 | **暂时取消**(之后可加) |
| 抓取物 | **软布球**,两个,外观完全一致 |
| 桌面 | 中间留干净操作区 |
| 性能 | Quest 3,帧率要求宽松 |
| 资源来源 | 自己在 Blender 建模为主;可用 Sketchfab 免费资源补充 |

## 4. 色板(提议 `[待确认]`)
从三张图合并提炼,偏暖、柔和、有层次:

| 用途 | 色 | 参考色号 |
|---|---|---|
| 墙面 | 奶油米色 | `#F3E3C8` |
| 地板/家具主木色 | 蜂蜜木色 | `#C98F57` |
| 深木(书柜、桌腿) | 暖棕 | `#8A5A3B` |
| 点缀绿(植物) | 鼠尾草绿 | `#8FAE6A` |
| 点缀冷色(靠垫、书脊、地毯) | 灰青蓝 | `#6F9EA8` |
| 点缀暖色(书脊、小物) | 柔珊瑚 | `#E58E73` |
| 台灯/灯光 | 暖琥珀 | `#FFC46B` |

规则:**墙和大件用低饱和,点缀用中饱和**;**大面积不用高饱和黄**,留给"答错时正确物体发光"的反馈色。

## 5. 房间与布局(提议 `[待确认]`)
- 房间约 **3.0 × 3.0 × 2.8 m**(近似立方体,小而精致);
- 患者坐在房间中央偏后,正面对书桌和前墙;
- 桌子靠前墙居中,约 **1.2 m 宽 × 0.6 m 深 × 0.74 m 高**;
- **操作区:** 桌面正中约 **0.9 × 0.5 m 完全留空**,放两个底座和感应垫;
- 台灯在桌面**后左角**,笔筒、书堆在**后右角**或侧边缘;
- 书柜靠**左侧墙**,小型;**右侧**放绿植或小边几;
- 墙面挂画一两幅,地上一块小地毯;
- 没有窗户时,暖阳用**烘焙的暖色方向光 + 墙面柔和光斑**表现(假窗影),保持"暖色阳光"的感觉 `[待确认:先这样,还是加一个小窗]`;
- 房间后方(患者身后)简化,患者转头能看到但不是重点;
- 虚拟椅子:患者坐在**真实椅子**上,虚拟世界里**不放椅子**,避免与身体错位。

## 7. Quest 3 技术规格(帧率宽松,但仍要稳)
| 项 | 要求 |
|---|---|
| 目标帧率 | 72 Hz,宽松 |
| 可见三角面 | 约 15–20 万以内 |
| 材质 | 尽量少;**一张调色板贴图 + 烘焙 AO**,大部分物体共用 |
| 贴图尺寸 | 调色板 1024;光照贴图 ≤ 2048 |
| 光照 | **烘焙**:一盏暖色平行光 + 少量灯;光照探针给两个可抓物体;**不用实时阴影** |
| 质感 | URP Lit,Smoothness 很低,哑光 |
| 透明 | 避免大面积半透明 |
| 轮廓 | 靠**倒角 + 明暗对比**,不用后处理描边 |
| 导出 | 1 单位 = 1 米;原点在物体底部;应用缩放;glb 或 fbx;**UV0 调色板,UV1 光照贴图** |
| 碰撞 | 只有桌面、地面和两个抓取物有碰撞;装饰物**无碰撞体**,防止误抓 |
| 命名 | `Room_Shell`、`Desk`、`Lamp`、`Bookshelf`、`Book_A`…`SoftBall`、`Pedestal`、`AnswerPad` |

## 9. 制作流程
| 阶段 | 内容 | 验收 |
|---|---|---|
| A 灰盒 | 用最简方块摆出房间、桌子、书柜、台灯、两个球的位置,导入 Unity | 在 Meta XR Simulator 里坐着看:比例、桌面高度、操作区是否舒服 |
| B 精模 | 倒角、造型、书的变体、软布球 | 面数达标,轮廓清楚 |
| C 材质与烘焙 | 调色板、AO、光照贴图、灯光 | 暖光柔和,色彩有层次,不发灰 |
| D 装配 | 在 Unity 里替换灰盒,接回游戏物体 | 抓取、感应垫、按钮和提示全部正常 |
| E 真机优化 | Quest 3 上看帧率与观感,调整 | 帧率稳定、无闪烁、无粉红材质 |

## 11. 两个可用模型的评估(2026-10-11,用 Blender 4.5 无界面模式实测)

| | `Study Room.fbx` | `рум1.fbx`(isometric) |
|---|---|---|
| 内容 | 暗色小卧室/书房:床、带抽屉的书桌、转椅、墙架、书、蜡烛、植物、台灯、落地灯、挂画、窗、地毯 | 粉色书房:白色长桌、转椅、扶手椅、窗帘、地毯、落地灯、墙架、绿植墙 |
| 三角面 | **73 万**(106 个网格,27 材质) | **1.26 万**(34 个网格,5 材质) |
| 尺寸 | 房间壳 4×4×4 m,物件比例真实(桌面 1.87 m) | 整体约 4.7×4.6×3.8 m |
| 主要问题 | 植物、蜡烛、仙人掌、落地灯等**面数极高**(单件 1.5–3 万,单本书 2240);整体超 Quest 预算 5 倍 | 配色偏粉,贴图是照片图集;面数很理想 |
| 作用 | **按件取用并减面**:墙架、书(换成简单盒体)、桌子、台灯、挂画、花盆 | **取其布局与件**:窗帘、扶手椅、地毯、落地灯、墙架;可整体换色 |

结论:**两个模型都不整体放进游戏**,而是当作"道具库":挑选合适的件 → 减面 → 重新上色成我们的色板 → 统一贴图。房间壳、桌子(操作区要干净)、软布球、底座、感应垫自建。

最贴近目标风格的是两张图 `roomvisual ref.png`(暖木色 + 奶油墙 + 柔和平涂色块)和 `room visual red.png`(干净的平涂低多边形、明确轮廓),这两张决定"配色和平涂感";两个 FBX 渲染出来偏暗/偏粉,配色不取。

## 12. 制作方式更新:不装 Blender MCP
实测 Blender 4.5 已能在命令行**无界面运行 Python**(导入、统计面数、渲染预览图都已跑通),所以:
- 建模用**脚本**生成,放在仓库 `art/scripts/`,可重复运行、可改参数重新生成;
- 每次渲一张预览图给我看,再迭代;
- 你随时可以用 Blender 打开 `art/blender/*.blend` 手动微调;
- **不需要装 MCP、uv、插件,也不需要 Sketchfab API Token**(模型由你提供)。
