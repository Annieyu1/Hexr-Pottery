## 2. 共用部分

- **场景**（2026-10-21）：T2 以 `Assets/Scenes/Pressure_Demo_Room.unity` 为模板重建，用的是 Blender 书房（`HexR_StudyRoom.fbx`）和它已经烘焙好的灯光（光照数据与 Pressure_Demo_Room 共用，不需要重新烘焙；琴和 UI 靠光照探针）。模板里压力演示的物体（`Game`、`Object_L/R`、`Pedestal_L/R`、`ControlPanel` 等）和旧的 `Environment` 都关掉了；书房桌上挡琴的 `Mug`、`Book_Stack` 也关掉；琴放在书桌中间偏患侧 12 cm，小猫在桌子后沿。其他任务（T1/T5/T11）仍用 `Assets/Scenes/1.unity`。

- **患者自己的手**：用 Quest 手部追踪（`TrackedHandFrame`），不再有固定的虚拟手。编辑器里没有追踪时，用灰色替身手，键盘 **1–5** = 拇指…小指：按住 = 手指抬起，松开 = 落下（这一刻算按键）。
- **校准**（每次 Start，第一次或按了 Recalibrate 时）：
  1. "Rest your hand on the table"：手放松平放，静止 3 s → 记下每根手指的静息姿势；**移动 VR 相机架，让真实桌面对上虚拟书桌**（±0.3 m 以内）；**琴键移到指尖下面**：琴垂直于手指方向，按患者的指距排开（详见 `art/t2-piano.md` §5）。
  2. 依次 "Lift your thumb / index …"：该键发光 + 指尖光点 + 触觉提示，患者把这根手指尽量抬起再放下（每指最多 5 s）→ 记下这根手指自己的"抬起姿势"和幅度。
  - L1 只做第 1 步（只需要对齐琴键）。
- 改进方案（降低非目标手指误判、联动计入评估、每指门槛、个人校准、桌面多来源对齐）见 docs/16（2026-10-24，未实现）。
- **按键检测 = 抬起再落下**（`FingerPressDetector`，2026-10-22）：手放在真实桌面上，手指按不下去，所以一次按键是**这根手指微微抬起、再落回桌面**；**落下的那一刻**算按键（发声、琴键下沉 0.18 s、计时），这时真实指尖也正好碰到桌子。
  - 看的是指尖相对本指根部的位置（在手的坐标系里）：整只手抬起或移动不算；按哪个键由手指决定，不看指尖落在哪个键上（不用碰撞体判断）。
  - 抬起超过本人校准幅度的 40%（`liftOn`）且至少 5 mm（`minLiftMeters`），再回到 20% 以下（`landOff`）= 一次按键。阈值都是估计值，要在头显里看 `flex.csv` 再调。
  - 校准学的是患者实际做的动作方向：抬不起手指的患者，可以让他往掌心勾一下再放回，同样能用（待和治疗师确认）。
  - 校准时移动不到 8 mm 的手指记为"不可用"（这根手指的音只能用 Skip 跳过）。抬起途中追踪丢失，这次不算。以后拿到 FlexR 接口只需替换 `Pose()`。
- **两种提示**（同时出现，各自可关）：
  - 触觉：目标手指振动（默认 25 Hz、0.4 s，可改为按压），强度 0.1–1；
  - 视觉：目标琴键发光 + 患者指尖上的光点（由任务直接控制，关掉视觉后不会因为手套刺激而亮）。
  - 两种都关时卡片提示 "Play the next note"（L3 里就是只凭记忆弹）。
- **琴声**（Sound 按钮）：琴本身的声音，不是提示。关掉后琴不出声。
- 可选 `keyTouch`（默认关）：患者按任何键时手指得到一下按压（按键手感，不区分对错）。
- **右手** C=拇指 … G=小指；**左手** C=小指 … G=拇指（同一个琴，从左到右）。

## 3. 三个层次

**L1 感受（Listen）**：琴键自己按下弹曲子，每个音对应手指被按压一下（强度 = 触觉强度，0.3 s）。速度 0.5×–1.5×（Slower / Faster），两个音之间不少于 0.6 s。患者不用做任何事。从选定的曲子开始轮流播放，默认 4 分钟。

**L2 学弹（Learn）**：等待模式，一个音一个音来。
1. 每个音开始时，**琴键和指尖发光 + 手指振动同时出现**（开着的才出现）。
2. 没按对之前，振动每 3 s 重复一次（`repeatCueSeconds`）；发光一直亮着。
3. **按错**：卡片变黄，标题 **"Try again"**（2 s 后恢复），发光继续，目标手指再振一次。
4. **按对**：进下一个音。**不会自动跳过**；患者实在按不了，治疗师（或患者）按 **Skip step**（键盘 S），日志记 `skipped`。
5. 治疗师随时可以关掉 / 打开视觉或触觉，当前这个音立刻生效，卡片提示语跟着变。

反复练选定的那首，默认 4 分钟。

**L3 测试（Test）**：治疗师先关掉要去掉的提示，选曲，按 Start。开着的提示在每个音开始时同时出现。**2026-10-25 起：别的手指触发不结束这个音，只有目标手指按下才算完成；只有超时没按才是 Miss**（详见 docs/16 §2.1）。每个音完成后，琴上方弹出评级（之前有别的手指触发过就降一档）：

| 评级 | 条件（`Wait` 模式：反应时；`Tempo` 模式：节拍误差的绝对值） |
|---|---|
| **Perfect!**（青色） | 按对，且 ≤ 1.0 s（Tempo：≤ 0.15 s） |
| **Very good**（绿色） | 按对，且 ≤ 2.0 s（Tempo：≤ 0.30 s） |
| **Nice**（黄色） | 按对，但更慢（Tempo：在半拍窗口内但更偏） |
| **Miss**（灰色） | 10 s 内目标手指没按（`missAfterSeconds`）、按了 Skip，或 Tempo 里窗口内没按 |

阈值是**占位值**，没有依据，要在患者身上试后再定（Inspector：`perfectSeconds`、`veryGoodSeconds`、`perfectTiming`、`veryGoodTiming`）。反应时包含蓝牙和气囊延迟（约 0.1–0.2 s）。

两种计时：
- `Wait`（默认）：等患者按，记反应时；
- `Tempo`：数 3 拍后按节拍走，每个音前后半拍内的按键算作答，记节拍误差。

弹完一遍，完成页显示 **Congratulations!**、**完成率**（目标手指按到的音 / 全部音，2026-10-25 起取代正确率）和用时（第一个音出现到最后一个音结束）。一次按对率只写进日志给治疗师。结果暂时不显示在治疗师面板上，完整数据在 `test_summary.json`。

## 4. 操作

- 运行时按钮行：Pause、Hints、**Skip step**（跳过当前音）。
- 治疗师面板（患侧对侧，Start/Pause 按钮下面）：L1 / L2 / L3（只在没运行时切换）、Sound（琴声）/ Visual / Touch 开关、Touch − / +、Slower / Faster、Next song、Recalibrate；上方文字显示当前设置。
- Hints 按钮 = 提示预设：发光 + 振动 → 只有振动 → 只有发光。
- 键盘：空格 开始/暂停，Esc 结束，**S** 跳过当前音，**L** 切层次，**M / V / T** 开关琴声/视觉/触觉，**- / =** 触觉强度，**[ / ]** 速度，**N** 下一首，**K** 重新校准，**1–5** 编辑器里模拟手指（按住 = 抬起，松开 = 落下）。
- Inspector（`PianoTask`）：`testTiming`、`testPasses`、`repeatCueSeconds`、`tryAgainSeconds`、`missAfterSeconds`、评级阈值、`touchCueKind`、`vibrationHz`、`cueSeconds`、`keyTouch`、`padOffset`（琴键顶面比指尖关节低多少，默认 8 mm）、`songs`。检测阈值在 `FingerPressDetector`。

## 5. 数据（`persistentDataPath/learning/<参与者>_T2_Piano_<时间>/`）

| 文件 | 内容 |
|---|---|
| `events.csv` / `session.json` | 同其他任务（每次触觉事件；剂量）；L3 时 `quiz_trials` / `quiz_correct` = 音数 / 正确数 |
| `piano_trials.csv` | L2、L3 每个音一行：目标键和手指、当时开着的提示、L3 评级、是否 Skip、反应时、节拍误差、实际按的键和手指、对错、按错次数、漏按、**联带运动的手指**（抬起期间一起抬的）、最大抬起程度、**最大抬起高度（mm）**、最大弯曲角度、**落下速度（mm/s，代替"力度"）**、开始抬起的时间、**从提示到开始抬起的时间**（`lift_reaction_s`；`reaction_s` 是到落下）、抬起到落下的时长 |
| `flex.csv` | 30 Hz 连续记录五指的抬起程度（progress，1 = 校准幅度）和弯曲角度 |
| `calibration.json` | 每指活动范围（mm）、是否可用、静息/按下姿势、琴键间距和位置 |
| `test_summary.json` | L3：完成率、一次按对率、误触、整手动作、用时、Perfect / Very good / Nice / Miss 个数、平均反应时、平均节拍误差、各手指、5×5 混淆矩阵（目标手指 × 实际手指） |

**"力度"说明**：手套只能输出压力，**测不了患者用了多大力**。记录的是抬起高度和落下速度，作为替代指标。

## 6. 已知限制

- 戴手套时 Quest 手部追踪是否稳定未知；手平放在桌上时手指互相遮挡，可能抖动 → 先在头显里看 `flex.csv` 再调 `pressOn` / `pressOff` / 平滑。
- 反应时含蓝牙（约 100 ms 合批）和气囊上升的延迟，只适合同一患者前后比较。
- 对齐桌面靠移动 VR 相机架：患者坐的高度看起来会跟着变；手不在桌上时（追踪到的手离书桌超过 0.3 m）不对齐，琴会悬空。头显里要确认一次。
- 拇指指尖比其他手指靠后，可能落在琴键前沿外面一点（白模手上约 4 mm）；真手上看情况调 `frontOverhang`。
- 和弦按"两个目标键都按到"判断，默认曲目里没有和弦。
- 界面文字为英文（同 T1）。
